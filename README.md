# WuWaSwitcher

WuWaSwitcher 是一个用于切换《鸣潮》游戏客户端版本的便捷工具，
支持在 Bilibili 客户端、官方客户端、WeGame客户端之间快速切换，
原理是对游戏的KrPcSdk_Mainland文件夹进行备份和恢复。

## 功能特性

- 🚀 **快速版本切换** - 一键在 Bilibili 、WeGame、官方客户端之间切换
- 💾 **备份系统** - 备份当前版本，支持版本恢复
- 🔍 **版本检测** - 自动识别当前游戏版本
- 🎮 **直接启动** - 快速启动当前配置的客户端

## 使用说明

### 1. 初始配置

首次使用需要配置客户端路径：

1. 点击 **"浏览"** 按钮选择游戏文件夹 `Wuthering Waves Game` 文件夹
2. （可选）点击 **"浏览"** 按钮选择 Bilibili 客户端的 `launcher.exe` 文件
3. （可选）点击 **"浏览"** 按钮选择官方客户端的 `launcher.exe` 文件
4. （可选）点击 **"浏览"** 按钮选择WeGame客户端的 `launcher.exe` 文件
5. 点击 **"保存配置"** 保存设置
6. 正确显示鸣潮游戏版本后（绿色字体），点击备份当前版本。

### 2. 版本管理

#### 首次切换版本（当前版本 -> 目标版本）

1. **目标是完成两个版本的首次备份。**

2. 点击`备份当前版本` 备份后，手动打开**目标版本**的客户端，点击修复游戏，等待修复完成

3. 再次点击备份当前版本，完成对**目标版本**的备份。

4. 然后就可以自由切换了。

### 3. 快捷功能

- **打开ScreenShot目录** - 快速访问游戏截图保存目录
- **查看使用说明** - 打开本文档
- **查看项目主页** - 访问 Gitee 项目页面

## 注意事项

1. **版本切换**
   
   - 切换版本前要先关闭 `鸣潮游戏进程` 和 `鸣潮启动器(客户端)` ，防止文件占用无法移动。程序也会检测相关进程并结束。

2. **鸣潮大版本更新 (如鸣潮2.7.0 -> 鸣潮2.8.0)**
   
   - **预下载：** 正常预下载即可。但要记住你是在B服还是官服进行的预下载，更新时也要在对应客户端进行更新，以避免出现问题。
   - **大版本更新：** 更新完成后请务必备份当前版本。
   - **大版本更新后如何切换：** 切换时，程序会检查备份的版本号是否低于当前版本，并且修改备份的版本号，如果运气好就不需要修复游戏了。

3. **UAC权限**
   
   - 本程序在切换版本前会检查游戏和启动器进程是否在运行并关闭它们，所以运行本程序需要UAC权限。当启动客户端时不会再次请求UAC权限。

4. **程序文件存放** 
   
   - 备份和配置均储存在程序的同级目录。最好将本程序在独立的文件夹中。

5. **关于WeGame端与官方客户端不兼容转换说明**
   
   - 由于WeGame客户端在游戏文件夹额外添加了WeGame有关文件，所以WeGame客户端无法识别官方客户端下载的游戏文件夹，但官方客户端可以识别WeGame客户端下载的游戏文件夹。
   
   - 所以，官方客户端 -> WeGame客户端的转换，请参考[NGA论坛的方法](https://ngabbs.com/read.php?tid=43249834&page=e&rand=724)
   
   - 你需要先在WeGame客户端点击下载，等相关文件夹生成后关闭WeGame客户端，
     把官方启动器的游戏文件，复制到wegame的游戏下载路径`WeGameApps/downloading/2002137/` 下，然后重新打开WeGame客户端继续下载，WeGame会自动校验文件，耐心等待完成即可。
   
   - 值得一提的是，WeGame下载游戏，会优先下载KrPcSdk_Mainland文件夹（包含版本转换所需文件）

## 系统要求

- Windows 10/11
- .NET Framework 4.7.2 或更高版本
- 《鸣潮》Bilibili客户端、官方客户端、WeGame客户端

## 故障排除

### 常见问题

**Q: 版本切换失败**
A: 确保游戏进程已完全关闭，文件不被占用，然后再次执行切换即可。

**Q: 备份文件损坏**
A: 修复游戏，重新备份即可
